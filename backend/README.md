# Execução do Java/Backend

Essa parte é responsável pelas requisições e pela existência do banco de dados.

Para executar a parte backend do projeto, vá até o arquivo ProjetoIndividualApplication e o rode.
Após isso, dentre das informações de execução do arquivo, estará a porta que eu settei (3060).
Pesquise por "http://localhost:3060/usuarios" para alcançar a base do UsuarioController.
Caso queira visualizar o banco de dados, acesse "http://localhost:3060/usuarios/h2-console",
Insira o nome da Database como "jdbc:h2:mem:tourly", o nome de usuário como "tourly" e a senha como "urubu100" para acessar.
